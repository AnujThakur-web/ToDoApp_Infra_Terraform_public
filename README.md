# ToDoApp_Infra_Terraform_public
## 📘 Overview
This project demonstrates how to use **Terraform** to automate the deployment of an **Ubuntu Linux Virtual Machine** on **Microsoft Azure**.
The infrastructure includes:
- Resource Group  
- Virtual Network & Subnet  
- Network Security Group (NSG)  
- Public IP & Network Interface  
- Linux Virtual Machine (Ubuntu 20.04 LTS)

- ## 🧩 Architecture Diagram
- Terraform Code → Azure Provider → Azure Cloud
↓
[Resource Group]
↓
[Virtual Network + Subnet]
↓
[Network Interface + Public IP]
↓
[Linux VM + NSG]
